# Frontend Core Web Vitals & APM Performance Metrics
## AI Agency Operating System (AgencyOS)

---

## 1. Core Web Vitals Performance Targets

- **Largest Contentful Paint (LCP)**: $< 2.2$ seconds (Target: $1.4\text{s}$)
- **Interaction to Next Paint (INP)**: $< 90$ milliseconds (Target: $45\text{ms}$)
- **Cumulative Layout Shift (CLS)**: $< 0.05$ (Target: $0.01$)

---

## 2. APM Throughput & Latency Thresholds

- **Standard REST API Latency ($P_{95}$)**: $< 150\text{ms}$
- **AI Proposal Synthesis Latency ($P_{95}$)**: $< 2500\text{ms}$
- **PostgreSQL Query Latency ($P_{95}$)**: $< 25\text{ms}$
